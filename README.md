# Workout Tracker

A mobile-friendly 3-day workout app with weight tracking per exercise.

Weights are saved automatically in your phone’s browser — no account, no token, no setup.

## Use on your phone

1. Make the repo **public** (free GitHub Pages).
2. **Settings → Pages** → deploy from **main** / **root**.
3. Open `https://michaelhuu96.github.io/fitness-app/` on your phone.
4. Optional: **Add to Home Screen** so it opens like an app.

## Multiple devices?

Each phone/browser keeps its own weights. If you only use **one phone** at the gym, you’re done.

To use two devices, you’d need either a sync token (GitHub) or manual copy — we removed that to keep things simple. Most people only need one device.

## Workout plan

- **Day 1 — Push**
- **Day 2 — Pull**
- **Day 3 — Legs + Shoulders**

Starred exercises are the main lift for each day.
